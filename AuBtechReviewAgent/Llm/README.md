# Llm

Everything about talking to the language model. `LlmProvider.cs` creates the chat service (Mistral, or any OpenAI-compatible server such as Ollama) from the settings in `LlmOptions.cs`, and routes the narrow checks to a fast model when one is set; `OpenAICompatibleChatService.cs` is the client both providers go through. `LlmJson.cs` asks for JSON, reads the answer robustly and sends a problem back to the model once; `LlmJson.Nulls.cs` reads a null from the model as a missing value, so the validator decides and nothing crashes. `LlmCallRecorder.cs` records every call (prompt, answer, model, temperature) for the run's ledger. `LlmRetryPolicy.cs` decides when a failed call is tried again, following the server's Retry-After on 429 and 503, and `ModelCallLimiter.cs` caps the calls in flight to one model across all runs on the server. `PromptTemplate.cs` hashes a prompt's fixed text, written with placeholders in place of the per-record data, for the cache keys that hold a prompt's inputs rather than the whole prompt, so an edited prompt is never answered from the cache. `PromptSafety.cs` marks text from papers and users as data, and flags instruction-like phrases (possible prompt injection); `PromptSafety.Patterns.cs` holds the patterns and says which are strong, aimed at the model, and which are weak mentions that stay on file but flag nothing; `PromptSafety.Rescan.cs` judges flags stored by an older scan again with the current patterns when a paper or statement counts them (#478). `HiddenText.cs` and `HiddenText.Html.cs` take out of a source's text what a reader never sees (invisible characters, hidden parts of a web page) before it is kept or read, and say what was taken out.
