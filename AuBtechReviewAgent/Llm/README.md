# Llm

Everything about talking to the language model. `LlmProvider.cs` creates the chat service (Mistral, or any OpenAI-compatible server such as Ollama) from the settings in `LlmOptions.cs`, and routes the narrow checks to a fast model when one is set; `OpenAICompatibleChatService.cs` is the client both providers go through. `LlmJson.cs` asks for JSON, reads the answer robustly and sends a problem back to the model once. `LlmCallRecorder.cs` records every call (prompt, answer, model, temperature) for the run's ledger. `LlmRetryPolicy.cs` decides when a failed call is tried again, following the server's Retry-After on 429 and 503, and `ModelCallLimiter.cs` caps the calls in flight to one model across all runs on the server. `PromptSafety.cs` marks text from papers and users as data, and flags instruction-like phrases (possible prompt injection); `PromptSafety.Patterns.cs` holds the patterns and says which are strong, aimed at the model, and which are weak mentions that stay on file but flag nothing. `HiddenText.cs` and `HiddenText.Html.cs` take out of a source's text what a reader never sees (invisible characters, hidden parts of a web page) before it is kept or read, and say what was taken out.
