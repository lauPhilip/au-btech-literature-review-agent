# Report

Everything the run hands over. `PrismaReviewEngine.Report.cs` assembles the PRISMA 2020 report. `MethodsSectionWriter.cs`, `PrismaFlowDiagram.cs` and `AiUseStatement.cs` write the methods, the flow diagram and the statement on AI use in code, from what the run actually did, never by the model. `ApaCitationBuilder.cs` and `JournalRankingMatcher.cs` build the references and venue ranks from the database metadata, and `BibliographyExporter.cs` writes BibTeX and RIS. `RunArchive.cs` builds the downloadable archive for every kind of review: the files every run has, the source texts and answers, and the module's own files; `RunManifest.cs` fingerprints every file in it. `ReviewPaper.cs` is the paper of every kind of review in one shape (title, abstract, introduction, method, data, results by theme, discussion, declarations, references), and `PaperLatex` writes it as `main.tex`; a module fills the shape and puts its own parts (method sections, figures, tables, evidence map) into its LaTeX slots, drawn in code. `PrismaReviewEngine.Archive.cs` fills it for a systematic review and adds the bibliographies.
