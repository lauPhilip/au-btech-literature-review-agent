# Verification

Checking that every citation points somewhere real and says what the sentence claims, for every kind of review. `Grounding.cs` is the entry point a module uses: it checks every citation of a text against its numbered sources and repairs the rejected ones once, and it re-checks a single citation on request. `CitationValidator.cs` removes citation numbers that are not in the reference list. `CitationSupportChecker.cs` compares each cited sentence with the cited paper and only accepts a verdict whose quote is found word for word in the paper; weak verdicts get a second, independent check. `PrismaReviewEngine.Recheck.cs` checks a single orange or red citation again after the run. `CitationRepairer.cs` rewrites a sentence with a rejected citation from the source's evidence, drops the citation or deletes the sentence, never adds a citation, and checks the changed sentences again. The prompts name the kind of review they serve, so the same check works for a systematic or a multivocal review.
