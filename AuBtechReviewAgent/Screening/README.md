# Screening

The screening stage: deciding for every record whether it meets the criteria. `PrismaReviewEngine.Screening.cs` runs the two independent screenings and turns their answers into the ledger. `PrismaReviewEngine.ScreeningPrompt.cs` holds the screening prompt (`ScreenPaperAsync`) and the peer-review filter, `ScreeningAnswer.cs` the model's answer and its checks, and `PrismaReviewEngine.ScreeningReview.cs` the human review of the decisions. When a screening prompt changes, raise `ScreeningPromptVersion` (in `PrismaReviewEngine.Screening.cs`) so older cached decisions are not reused. The screening steps (`ScreeningProcedure`) and the answer format (`ScreeningAnswerFormat`) are shared with the multivocal review's grey screening (`Modules/Multivocal/MultivocalScreening.cs`), so both pools are screened with the same care; changing them changes both, so raise both prompt versions. `ExclusionReasons.cs` groups the exclusions for the funnel and the report, and `ScreeningEvaluation.cs` measures agreement (Cohen's kappa) and accuracy against human decisions.
