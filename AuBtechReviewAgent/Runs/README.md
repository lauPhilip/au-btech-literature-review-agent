# Runs

The run folders, for every kind of review. `RunStore.cs` knows where each run lives and whether it has started, gives the browser that started a run its edit key (so only that browser can change the run), keeps the reviewer's notes on citations and studies, and deletes a run. Pages and modules use the store instead of a review engine; `PrismaReviewEngine.Ownership.cs` and `PrismaReviewEngine.Notes.cs` only pass through to it so older callers keep working. `RunMetrics.cs` and `RunMetrics.Build.cs` work out each finished run's quality figures for the Metrics page, `RunMetricsStore.cs` keeps them, `MetricsOverview.cs` turns them into the figures the Metrics page shows, `PrismaReviewEngine.Metrics.cs` writes them when a systematic run finishes, and `SessionCleanupWorker.cs` deletes runs after the retention period. `RunFolderStamp.cs` fingerprints what a run folder holds, for the downloads' ETag and the kept archive. `RunLedgerWatch.cs` reads a running review's ledger for the dashboard, and parses it again only when it changed. `ToolVersion.cs` gives the version of TraceableAI a run was made with, and how to show and cite it.
