# Runs

The run folders, for every kind of review. `RunStore.cs` knows where each run lives and whether it has started, gives the browser that started a run its edit key (so only that browser can change the run), keeps the reviewer's notes on citations and studies, and deletes a run. Pages and modules use the store instead of a review engine; `PrismaReviewEngine.Ownership.cs` and `PrismaReviewEngine.Notes.cs` only pass through to it so older callers keep working. `RunMetrics.cs` records each finished run's quality figures for the Metrics page, and `SessionCleanupWorker.cs` deletes runs after the retention period.
