# Runs

The run folders, for every kind of review. `RunStore.cs` knows where each run lives and whether it has started, gives the browser that started a run its edit key (so only that browser can change the run), keeps the reviewer's notes on citations and studies, and deletes a run. Pages and modules use the store instead of a review engine; `PrismaReviewEngine.Ownership.cs` and `PrismaReviewEngine.Notes.cs` only pass through to it so older callers keep working. `ReportEditLog.cs` is report-edits.json, the history of the reviewer's edits of the report, with which edit each sentence shows now and the sentence the report and the statement on AI use give about them. `RunMetrics.cs` and `RunMetrics.Build.cs` work out each finished run's quality figures for the Metrics page, `RunMetrics.Pools.cs` holds a multivocal run's figures for each pool, `MetricsExport.cs` writes every run's figures as CSV and JSON for the downloads (columns described in `docs/metrics-dictionary.md`), `MetricsPrices.cs` is the optional price table for their estimated cost (off unless set), `LlmUsage.cs` reads the tokens of each model call from llm-calls.json and adds up a run's effort by stage and by model (`StageCost`), `RunMetricsStore.cs` keeps them, `MetricsOverview.cs` turns them into the figures the Metrics page shows, `PrismaReviewEngine.Metrics.cs` writes them when a systematic run finishes, and `SessionCleanupWorker.cs` deletes runs after the retention period. `RunFolderStamp.cs` fingerprints what a run folder holds, for the downloads' ETag and the kept archive. `RunLedgerWatch.cs` reads a running review's ledger for the dashboard, and parses it again only when it changed. `ToolVersion.cs` gives the version of TraceableAI a run was made with, and how to show and cite it. `GalleryStore.cs` is the gallery of example reports in `App_Data/gallery/`, kept like the metrics outside the run folders: a finished run's owner can add its report with an explicit yes, one review (`GalleryEntry.cs`, `GalleryFingerprint`) has one entry that a newer run replaces, and `GallerySnapshot.cs` says which report files are copied (never the notes or the edit key) and what the catalogue card shows.
