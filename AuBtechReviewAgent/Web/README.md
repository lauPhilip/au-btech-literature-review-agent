# Web

Helpers for the website around the review. `SiteSeo.cs` serves robots.txt, the sitemap and structured data; `SiteHealth.cs` answers `/health`. `SecurityHeaders.cs` sets the Content-Security-Policy and the other security headers, and `SecurityUtility.cs` cleans API keys and other input before they are used. `SiteRateLimits.cs` rate-limits every plain HTTP address per client address and `SiteRateLimits.Server.cs` caps request bodies and what a live connection may hold; `ActionLimiter.cs` limits the costly actions of the live connection per address and hour, and `ArchiveUpload.cs` makes the upload on `/verify` safe (one check at a time, a temporary file, zip files only). `RunQuotaService.cs` counts free runs per network address, and `RunQuotaService.Cancel.cs` gives a cancelled run back at most once a day per address. `SiteCulture.cs` makes every page format numbers and dates as the paper does, whatever culture the server runs in. `ResponseCompressionSetup.cs` compresses JSON, XML and the text downloads, and never an answer that carries a secret. `Glossary.cs` holds the plain-language explanations shown as help, `UiStateContainer.cs` is the dashboard's state for one browser session, and `UserApiKeys.cs` is the keys a user entered. `WorkspaceDownloads.cs` maps the run downloads under `/api/workspace/{id}/` and answers a repeat download of an unchanged run with 304 Not Modified. `MetricsDownloads.cs` serves the Metrics page's figures as `/metrics/runs.csv`, `/metrics/runs.json` and `/metrics/stages.csv` (`Runs/MetricsExport.cs`). The API documentation page (`/docs/api`) uses three files here: `ApiSwitch.cs` says whether the API is on and links the OpenAPI description to the page, `ApiDocExamples.cs` holds every example on it (checked against the real API in a test), and `ReadingEase.cs` is the Flesch Reading Ease of the release check, in C#.
