# Mermaid

`mermaid.min.js` is Mermaid 11.17.2 (`dist/mermaid.min.js` from the npm package `mermaid@11.17.2`), served by
the app so the Review Output page loads no script from a CDN. Mermaid is MIT-licensed; see `LICENSE`.

To update: `npm pack mermaid@<version>`, copy `package/dist/mermaid.min.js` and `package/LICENSE` here, and
change the version in this file and in `wwwroot/js/mermaid-render.js`.
