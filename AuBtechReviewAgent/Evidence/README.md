# Evidence

What the review knows about each included study. `DocumentRAGUtility.cs` finds a legal open-access full text, downloads it and splits it into page-tagged chunks; `DocumentRAGUtility.Download.cs` downloads a PDF from public addresses only, with at most five checked redirects, and stops when the run is cancelled (#588), and `FullTextFile.cs` names each PDF by a key of its own paper and writes the record beside it (#587). `PdfVisibleText.cs` reads a PDF page letter by letter and leaves out the letters a reader never sees: invisible, tiny, off the page, in a layer that is off, or white with nothing under them (#534). `DocumentRAGUtility.Unpaywall.cs` asks Unpaywall and keeps the answer a PDF was found through in `SourceResponses/`, since it records the paper's licence. `StudyExtractor.cs` fills the extraction form and the MMAT appraisal for each study, and checks in code that every value comes with a quote that is really in the paper. `RiskOfBias.cs` turns the MMAT answers into the traffic-light view of Table A.3, in the appendix after the references. With research questions, `StudyExtractor.Questions.cs` directs the extraction at them: the questions' words weigh double when the passages are chosen, and each key finding names the question it bears on, checked in code (up to two more findings are kept only for a question none of the first three answers). Every systematic extraction is cached by its prompt, `StudyExtractor.PromptVersion` and the model, so a rerun on the same studies extracts the same values; raise the version when the prompt changes. Without research questions the prompt is as before, and the multivocal MMAT appraisal, which passes no `ExtractionFocus`, is unchanged.
