# Gallery

The public gallery of example reports (`/gallery`). `GalleryOffer.razor` is the owner's offer on a finished run's report page: the consent text, the yes, and withdrawing again. `GalleryText.cs` holds the consent text and the rule for duplicates that more than one page shows. `GallerySearch.cs` is the catalogue's search box, `GalleryCitation.cs` and `GalleryCite.razor` the "Cite this report" block, and `GalleryCard.cs` the lines a card shows, with the citation support and the self-check. The pages are `Components/Pages/Gallery.razor` (the catalogue), `GalleryReport.razor` (one version of a report, drawn by the report page from its copy, with `GalleryVersions.razor`, the list of versions) and `GalleryCompare.razor` (two versions side by side, from the rows `GalleryComparison.cs` works out in code from the stored files); what is kept, and the rules for adding versions, capping, hiding and withdrawing, are in `Runs/GalleryStore.cs`.
