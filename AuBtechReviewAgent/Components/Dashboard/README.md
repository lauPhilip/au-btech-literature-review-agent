# Components/Dashboard

Parts of the dashboard (`Pages/Home.razor`). Before a run: the composer with the question (`ReviewComposer`), the criteria panel beside it (`CriteriaPanel`) and the help line under a field (`FieldHelp`); these two write the form into `UiStateContainer`, and the page starts the run. For a run: the progress bar and the database status (`RunProgressPanel`, `SourceStatusNote`), the PRISMA funnel (`PrismaFunnel`), the human screening review (`ScreeningReviewPanel`), the Cancel review card (`CancelRunCard`, which asks first and leaves the cancelling to the page) and the summary of a finished run (`RunSummaryCard`). The run parts only display what the engine has recorded; none of them changes a run on its own. `Pages/` holds only routable pages, and `Layout/` the header, footer and other parts every page shares.
